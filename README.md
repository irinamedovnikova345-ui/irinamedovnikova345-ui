# Привет! Я Ирина Медовникова 👋

Разрабатываю приложения от идеи до запуска: веб-сервисы (Next.js, React), мобильные приложения (React Native) и Telegram-боты (Python). Сама проектирую интерфейс, пишу код, настраиваю сервер и базу данных, тестирую и выпускаю в работу. Работаю в связке с ИИ-инструментами, поэтому быстро довожу идею до рабочего продукта, а там, где это полезно пользователям, встраиваю ИИ в сам продукт — перевод, распознавание фото и речи, умные ответы.
